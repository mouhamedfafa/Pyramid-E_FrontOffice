Règles du fichier

Vérifiées avant toute écriture.

  • Format .xlsx uniquement, 10 Mo maximum. Les fichiers avec macros (.xlsm) sont refusés.
  • 1 000 lignes maximum par feuille. Ne renommez pas les feuilles et ne modifiez pas les lignes 1 à 5.
  • Les ID sont automatiques : saisissez un titre, l'ID apparaît (FOR-IMP-001…).
  • Dans Module et Section, le rattachement reprend la ligne du dessus ; choisissez un autre ID dans la liste pour changer de formation ou de module.
  • Les ID …-IMP-… sont provisoires : la plateforme attribue les ID définitifs.
